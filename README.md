# Таблица счетов

React приложение для управления таблицей счетов с возможностью добавления новых записей.

## 🚀 Быстрый старт

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для production
npm run build
```
